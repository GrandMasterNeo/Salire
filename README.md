# Salīre™ — Calcudoku

**Early experimental development (pre-alpha). Not ready for release.**

Salīre is derived from the open-source Gauguin game. Original authors and contributors retain credit and rights to their inherited work. This is an independent repository, not necessarily a GitHub-linked fork.

Development predecessor: [Gauguin-Logic-Tests](https://github.com/GrandMasterNeo/Gauguin-Logic-Tests).

## Development goals

3×3–11×11 puzzles, exactly one solution, human deduction without guessing, correct arithmetic and connected cages, calibrated difficulty, reproducible seeds and preserved pencil marks. These are requirements, not certified results.

Source migration and verification of the exact upstream license, attribution, dependencies, privacy and regression results remain pending. See [release compliance](RELEASE-COMPLIANCE.md) and [attribution](NOTICE.md). No production release is announced.
